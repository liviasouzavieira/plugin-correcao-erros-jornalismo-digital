Plugin de correção de erros para o jornalismo digital

Biblioteca client-side (CSS + JavaScript puros) que qualquer redação pode instalar em seu site para sinalizar, de forma padronizada, correções, direitos de resposta, trechos excluídos e conteúdos novos publicados após a matéria original. Autocontida, sem dependências, com expiração automática das marcações após 24 horas.

O que este plugin faz

O plugin materializa, em código instalável, a taxonomia proposta pela pesquisa: erro factual, grafia, imprecisão, retificação em declaração, direito de resposta, trecho excluído e conteúdo novo. Cada categoria tem cor, comportamento e regra de permanência definidos — correções ficam registradas permanentemente; marcações de conteúdo novo desaparecem após 24 horas mantendo o texto; trechos excluídos somem por completo depois desse mesmo intervalo.

Como instalar em WordPress

O plugin funciona em qualquer CMS que aceite HTML personalizado, mas WordPress tem particularidades. Há um guia dedicado explicando três caminhos de instalação (do mais simples ao mais formal) e os cuidados específicos do editor Gutenberg: integração com WordPress (PT) · WordPress integration (EN).

Ver o plugin em uso numa matéria real

Este plugin foi extraído de um protótipo de página web desenvolvido paralelamente à pesquisa — uma matéria fictícia sobre um conflito no Irã que aplica todos os padrões em contexto jornalístico realista. O protótipo está disponível em outro repositório: liviasouzavieira.github.io/prototipo-correcao-erros-jornalismo-digital.
