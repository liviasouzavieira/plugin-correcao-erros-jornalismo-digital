Plugin de Correção de Erros

Torna as correções jornalísticas mais visíveis e rastreáveis. Funciona em qualquer CMS: basta incluir o CSS e o JS desta página e adicionar atributos data-cde-* no HTML.

Exemplo: artigo com correções

Conselho de Segurança da ONU convoca reunião de emergência após escalada no Irã

Por Ana Martins · 17 de abril de 2026, 09:42

Em sessão extraordinária realizada na manhã desta sexta-feira, o Conselho de Segurança da ONU aprovou uma resolução pedindo moderação a todas as partes envolvidas no conflito. Quatorze países votaram a favor da resolução, com uma abstenção e nenhum voto contrário.

O texto da resolução demanda o fim imediato das hostilidades e o retorno das partes à mesa de negociação. Segundo fontes diplomáticas ouvidas pela reportagem, a votação reflete um raro alinhamento entre membros permanentes do Conselho.

Atualização (14:20): o Itamaraty informou, em nota divulgada minutos depois da votação, que o Brasil considera o resultado "uma vitória do multilateralismo" e seguirá apoiando os esforços diplomáticos no Conselho de Segurança.

Padrões além das correções de erro

O plugin também suporta três padrões que vão além de "corrigir um erro": conteúdo novo (acréscimo após a publicação), direito de resposta (texto concedido judicialmente) e trecho excluído (registro de remoção). Cada um abaixo é uma demonstração isolada, com os atributos visíveis no código-fonte.

→ Conteúdo novo · data-cde-novo

Caixa amarela com o selo "NOVO · ACRESCENTADO HÁ Xh". Após 24h, a marcação visual some e o texto permanece como parágrafo normal. Lead-ins em negrito (<strong>Atualização (HH:MM):</strong>) também são removidos automaticamente.

Atualização (13:50): agências internacionais confirmaram que o secretário-geral da ONU comparecerá pessoalmente à sessão da próxima semana — informação não disponível na primeira versão da reportagem, divulgada apenas com o nome do representante permanente.

→ Trecho excluído · data-cde-excluido

Bloco cinza tracejado: registra a remoção com motivo + texto original colapsável. Após 24h, todo o bloco (incluindo o texto original) some da página, deixando a versão definitiva no arquivo público.

→ Direito de resposta · data-cde-resposta

Bloco teal permanente. Publica integralmente o texto da resposta concedida judicialmente, com referência à decisão e crédito da fonte solicitante. Não some — é parte do registro público.

Arquivo de correções
Como instalar em qualquer CMS

1. Copie o CSS e o JS

Abra este arquivo em um editor e copie tudo que está entre as marcas ▼ INÍCIO DO PLUGIN ▼ e ▲ FIM DO PLUGIN ▲ — há dois blocos (CSS dentro do <style> e JS dentro do <script>). Cole nos templates do seu CMS (WordPress, Ghost, Drupal, Sanity, etc.) ou hospede como dois arquivos estáticos (cde.css, cde.js).

2. Marque correções inline no texto

Sempre que uma palavra ou trecho for corrigido dentro do corpo da matéria, envolva o texto novo em um <span> com os atributos abaixo. O plugin adiciona destaque visual e tooltip com o texto original.

<span data-cde-inline
      data-cde-antes="Quinze países votaram a favor"
      data-cde-motivo="Correção: eram 14 votos, não 15.">
  Quatorze países votaram a favor
</span>

3. Insira um bloco de errata

No topo ou rodapé da matéria, adicione um <div> com os dados da correção. O plugin gera um cartão com badge de tipo, data, motivo e diff antes/depois.

<div data-cde-bloco
     data-cde-tipo="factual"
     data-cde-titulo="Número correto de votos"
     data-cde-motivo="A versão inicial informava 15 países; o correto é 14."
     data-cde-antes="Quinze países votaram a favor."
     data-cde-depois="Quatorze países votaram a favor."
     data-cde-data="2026-04-17T14:20:00-03:00">
</div>

Valores possíveis para data-cde-tipo: factual, grafia, imprecisao, declaracao, outro. Esta taxonomia está alinhada com a usada na landing page de pesquisa (veja README): factual (vermelho) para erros de fato, grafia (índigo) para erros ortográficos, imprecisao (laranja) para informação vaga ou número impreciso, declaracao (roxo) para erros em citações ou depoimentos, e outro para casos que não se encaixam.

4. Mostre o arquivo de correções

Em uma página de arquivo ou no rodapé da matéria, inclua o container. O plugin lista todas as correções da página e adiciona filtros.

<div data-cde-lista
     data-cde-titulo="Correções desta cobertura"
     data-cde-subtitulo="Lista auditável de todas as correções.">
</div>

5. Botão de comunicar erro

Em qualquer lugar do template, adicione um <button> com o atributo data-cde-abrir-form. O plugin associa o clique à abertura do modal.

<button data-cde-abrir-form class="cde-botao-reportar">
  Comunicar erro
</button>

Para um botão flutuante fixo, habilite via configuração JS (ver passo 9).

6. Direito de resposta

Quando uma fonte conquistar judicialmente o direito de responder algo dito sobre ela, use data-cde-resposta. O plugin renderiza um bloco teal permanente com o texto integral, a decisão judicial e o crédito.

<div data-cde-resposta
     data-cde-de="Senador X"
     data-cde-decisao="8ª Vara Cível · proc. nº ..."
     data-cde-data="2026-04-17T16:45:00-03:00"
     data-cde-introducao="Em cumprimento à decisão..."
     data-cde-texto="Esclareço que minha fala foi extraída de contexto..."
     data-cde-rodape="Texto publicado em sua íntegra, sem edição editorial.">
</div>

7. Trecho excluído (some após 24h)

Quando um trecho da reportagem é removido após a publicação, use data-cde-excluido. O plugin mostra um bloco cinza tracejado com o motivo + opção de expandir o texto original. Importante: o bloco inteiro (incluindo o texto original) some automaticamente da página depois de 24 horas, deixando apenas a versão definitiva no arquivo público.

<div data-cde-excluido
     data-cde-motivo="inverificabilidade"
     data-cde-marcado-por="Editor de Internacional"
     data-cde-data="2026-04-17T15:10:00-03:00"
     data-cde-explicacao="A primeira versão atribuía a fontes anônimas..."
     data-cde-original="O texto entre aspas que estava ali.">
</div>

8. Conteúdo novo / atualização (marcação some após 24h)

Para destacar um trecho que foi acrescentado após a publicação inicial — uma atualização de contexto, um acréscimo de fala, uma nova reação — use data-cde-novo. O plugin envolve o conteúdo numa caixa amarela com selo "Novo · acrescentado há Xh". Depois de 24 horas, a caixa amarela e o selo somem; o texto permanece no fluxo do artigo (e qualquer lead-in em negrito como "Atualização (HH:MM):" também é removido para o texto ler como matéria normal).

<div data-cde-novo data-cde-data="2026-04-17T14:20:00-03:00">
  <p><strong>Atualização (14:20):</strong> conteúdo novo aqui...</p>
</div>

9. Indicador de "publicação recente" (últimas 24h)

O plugin aplica automaticamente a classe .cde-recente e um badge em correções cuja data-cde-data estiver dentro das últimas 24 horas. A mesma janela rege a expiração dos blocos data-cde-excluido e data-cde-novo. A janela pode ser ajustada na configuração.

10. Configuração avançada (opcional)

Se quiser customizar comportamento, chame CorrecaoDeErros.init() antes do fim do <body>. Todas as opções são opcionais.

<script>
  CorrecaoDeErros.init({
    // URL para onde enviar reports de erro (POST JSON)
    endpoint: "/api/reportar-erro",

    // Janela de "recente" em horas (padrão: 24)
    janelaRecenteHoras: 24,

    // Mostra botão flutuante de reportar erro
    botaoFlutuante: true,
    posicaoBotao: "bottom-right", // ou bottom-left, top-right, top-left

    // Callback em vez de (ou além de) endpoint
    aoReportar: function(dados) {
      console.log("Erro reportado:", dados);
      // dados: { tipo, descricao, email, url, dataEnvio }
    },

    // Substitui o texto da interface (i18n / tom editorial)
    rotulos: {
      botaoReportar: "Comunicar erro",
      modalTitulo: "Comunique um erro",
      modalSubtitulo: "Toda correção é revisada pela editoria antes de publicação.",
      // ...demais rótulos em CorrecaoDeErros.rotulosPadrao
    }
  });
</script>

11. API programática

Se o CMS já tiver as correções em um banco, renderize-as via JS em vez de usar data-cde-bloco:

CorrecaoDeErros.registrar([
  {
    tipo: "factual",
    titulo: "Nome correto do porta-voz",
    motivo: "O texto inicial trazia 'João Silva' — o nome correto é 'Jorge Silva'.",
    antes: "João Silva",
    depois: "Jorge Silva",
    data: "2026-04-17T10:12:00-03:00"
  }
]);
CorrecaoDeErros.renderLista(document.querySelector("#arquivo-correcoes"));
Acessibilidade e compatibilidade
  • Navegação por teclado: modal abre com Enter/Espaço, fecha com Esc.
  • Foco gerenciado: ao abrir modal o foco vai para o primeiro campo; ao fechar retorna ao botão.
  • Sem dependências externas (apenas HTML, CSS e JS padrão). Funciona com qualquer CMS.
  • Namespace .cde-* e data-cde-* evitam conflitos com o tema existente.
  • Compatível com navegadores modernos (Chrome, Safari, Firefox, Edge — últimas 2 versões).
